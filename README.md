# Iris Flower Classification 🌸

This project uses Machine Learning to classify iris flowers into three species:

- Setosa
- Versicolor
- Virginica

based on flower measurements.

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

# Dataset

The dataset used is the famous Iris dataset provided by Scikit-learn.

Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target:
- Iris flower species

---

# Machine Learning Model

Model Used:
- Logistic Regression

---

# Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Visualization
4. Train-Test Split
5. Model Training
6. Prediction
7. Accuracy Evaluation

---

# Accuracy

The model achieves high accuracy on the testing dataset.
